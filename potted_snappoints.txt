NORMALIZATION (use in React Native):
  IMPORTANT: backgrounds are drawn with resizeMode="cover", which scales the
  image to FILL the container (preserving aspect ratio) and center-crops the
  overflow. A naive (screenWidth/1376) scale is WRONG when the container aspect
  ratio differs from 1376:768. Use the cover transform instead:

    scale   = max(containerW / 1376, containerH / 768)
    offsetX = (containerW - 1376 * scale) / 2
    offsetY = (containerH -  768 * scale) / 2
    screenX = rawX * scale + offsetX
    screenY = rawY * scale + offsetY

  This is implemented in src/engine/project.js (projectPoint / projectSize)
  and used by all snap-point lookups + sprite sizing.
